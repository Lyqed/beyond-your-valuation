# Beyond Your Valuation rename

This source change renames What You Actually Own to **Beyond Your Valuation**
and sets `https://beyondyourvaluation.com` as the canonical domain. It starts
from source commit `c396f7906108b7877ee8eb1e87a456e08baa2d29` in the existing
Sites checkout.

The visible wordmark, accessible home label, home and methodology metadata,
Open Graph and Twitter cards, README links, private package name and JSON
download filename use the new name. Each page declares its own canonical URL.
The editable `public/og.svg` retains the established ownership-board artwork
with the updated wordmark; `public/og.png` is rendered from that SVG.

The green, lavender and peach design, model arithmetic, controls, receipts,
scenario version and URL-fragment decoding are unchanged. Saved scenario
fragments can still be loaded. The report filename is now
`beyond-your-valuation-scenario.json`; its data format is unchanged.

The GitHub repository has not been renamed. Source links intentionally remain
`https://github.com/Lyqed/what-you-actually-own`. Earlier release documentation
retains the project name and domain that were current for those releases.

## Release handoff

The parent release workflow owns the Sites source package, commit, publication
and domain activation. This change does not alter `.openai/hosting.json`,
hosting identities, domain records or DNS. A canonical URL in generated HTML
does not establish that the new domain is serving the site.

Render the native Open Graph asset from this checkout with:

```sh
node --input-type=module -e "import sharp from 'sharp'; await sharp('public/og.svg').png().toFile('public/og.png');"
```

Run required checks with `npm test`, `npm run build`, and `npm run typecheck`.
Serve `out/` locally and run `scripts/qa-browser.mjs` with `BASE_URL` and, if
needed, `PLAYWRIGHT_MODULE`. The browser checks include both page metadata,
desktop/mobile wordmark fit, the existing source link, the renamed download,
model interactions and saved-scenario compatibility.
