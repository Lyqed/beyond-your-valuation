# What this version does not claim

- **Exit:** no multiple preferred classes, seniority interactions, participation caps, SAFEs, notes, dividends, debt, option exercise costs, unvested options, earn-outs, escrow or non-cash consideration. The founder tax rate is an arithmetic input, not jurisdiction-specific guidance.
- **Portfolio:** no return predictions, probabilities, Monte Carlo paths, statistical correlations, inflation, long-term withdrawals, leverage, transaction fees or investment taxes. Liquidity windows are chosen assumptions. All assets are USD-denominated; only the family expense is ILS-denominated. Funding commitments are assumed, not inferred from invested asset balances.
- **Insurance:** no premium comparison, suitability assessment, interpretation of a real contract, underwriting or claims decision. Legality, sanctions, consent requirements, disputes, multiple incidents, restored limits, coinsurance and borrowing costs are outside the model. Coverage does not guarantee a real payment or date.
- **Connections:** exit proceeds can be copied into the personal portfolio as a snapshot. The fictional insured business is separate. There is no single consolidated balance sheet or automated feedback from business loss into personal wealth.
- **Validation:** tests verify model arithmetic and input boundaries. They cannot establish whether these simplifications are appropriate for a person's circumstances.
- **Sharing:** a scenario URL exposes its inputs to recipients. The application does not upload financial data; ordinary hosting requests are still logged according to the host's practices.

Use actual documents and appropriate qualified advisers for real transactions or financial decisions. This project is an educational experiment.
